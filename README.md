Project Description
Command Injection: Command injection is a security vulnerability where an attacker passes unauthorized commands through an application directly to the underlying operating system. This allows them to bypass security controls to access, modify, or delete protected data. 

This project will seek to demonstrate the differences between a vulnerable application with a patched version to analyze the root cause and potential implications of command injection. It will detail both the attack and defense programming controls required to mitigate the flaw effectively.
